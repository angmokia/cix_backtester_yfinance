# cix_backtester_yfinance
Customisable backtester

Here you can:
- Create custom tickers (similar to BBG CIX) as your target variable
- Check the CIX beta against a benchmark
- Condition a trade on several indicators (level/rolling return/cumulative sum) on available tickers
- Check historical hit rate and a summary of statistics of returns
- Time series analysis of CIX
